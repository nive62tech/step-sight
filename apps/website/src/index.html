How do I install Desktop Guide?+

Download the ZIP, extract all files to a folder you can write to, and open DesktopGuide.App.exe. Windows 11 x64 is required. The .NET runtime is included. This preview is unsigned, so Windows may display a security warning. No installer or automatic updater is included.

Do I need an account?+

The offline walkthrough works without signing in. Live cloud guidance uses invite-only pilot accounts. Downloading the app does not create an account or grant pilot access.

What can the development preview do?+

The app includes guided lesson flows, optional visual pointing, questions, and separately approved single-action demonstrations. Lesson templates include Notepad, VS Code, and the practice sandbox. Real application workflows and accessibility are still being qualified. This website's demo is an illustration, not a live AI session.

What does the app see?+

You select and preview a window or monitor before granting observation. Live guidance sends frames from that selected source for cloud inference. The app is designed not to persist raw learner screenshots or audio. The offline walkthrough does not inspect your screen, and this website never captures your desktop.
