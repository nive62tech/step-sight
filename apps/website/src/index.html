How do I install Desktop Guide?+

Download the ZIP, extract all files to a folder you can write to, and open DesktopGuide.App.exe. Windows 11 x64 is required. The .NET runtime is included. This preview is unsigned, so Windows may display a security warning. No installer or automatic updater is included. To update, close the app from its tray menu and extract the latest ZIP into a new folder. Older extracted copies do not update automatically.

Do I need an account?+

Yes. The latest build needs an invited pilot account and an internet connection for live guidance. Sign in with your invited email and the permanent password you set. Downloading the ZIP does not create an account. Offline walkthroughs have been removed from the current version; the older archived pilot has different behavior.

What can the development preview do?+

Start from a prompt or the current-window shortcut, follow live screenshot guidance in the floating companion, retry a target, check your result, or allow autonomous actions. Speak a prompt, review its text, or connect the phone controller from desktop settings. Chrome is the default for new browser tasks; name Edge or Firefox in your prompt if preferred. Full real-application workflows, native overlay placement, voice and accessibility are still being qualified. This is an unsigned development pilot; the website demo is illustrative.

What does the app see?+

Starting a task sends your prompt for cloud planning, then shares live screenshots of the task window for guidance. The current build uses screenshots only; DOM and Windows accessibility inspection are disabled. An optional manual source/preview flow supports privacy masks. The app is designed not to persist raw learner screenshots or audio. This website never captures your desktop.

Will it click, type or deploy for me?+

Choose Guided to follow the cursor yourself, or Autonomous to let the agent click, scroll and type in your selected task window. Autonomous tasks need your local permission and run for up to 30 actions or 10 minutes. You handle login, CAPTCHA, billing and final submissions. Moving your mouse or typing pauses the agent.

What if the target is missing or the page is loading?+

The companion shows an animated analysis indicator and retries temporary analysis failures up to three times with fresh images. Autonomous mode also rechecks blocked targets before pausing. Resume reconnects, reads the current screen and keeps your chosen mode. Stop cancels locally and clears permissions immediately. Bring the task window back to the front if focus is needed.

How do I pause, stop or exit?+

Pause is available in the expanded companion. Stop is available on the dock, in the tray and through Ctrl+Alt+Shift+S when the shortcut is registered. Stop ends capture and cancels pending work; resuming requires fresh observation consent. Closing the main panel leaves the companion running. Choose Exit from the tray to quit.
