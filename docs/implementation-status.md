The earlier browser-accuracy follow-up added local Windows UI Automation inspection behind a Platform interface. Outside sandbox/practice evaluation, Guide mode matches the image-selected exact label and action role to one enabled, unmasked browser control, converts its physical bounds through the capture geometry, checks its current identity and hit-test visibility, then validates a fresh image before drawing. It never invokes a browser action, changes an input proposal, reads field values, sends browser labels to the cloud or uses approximate image coordinates to break duplicate-label ties. Inspection has a two-second caller deadline and at most one background worker. Stop rejects late results. Chrome/Edge are primary targets; Firefox and inaccessible custom controls remain limited. Native browser integration is implemented but unqualified: the Computer Use helper still fails to initialize. Fifteen additional deterministic cases cover corrected geometry, DPI/negative origin/crop, duplicate/disabled/masked/password controls, exact matching, sandbox isolation and late Stop.
