# Using Desktop Guide

**Phone control:** in the r16 Windows build, open **Preferences → Control from your phone**, optionally allow Autonomous phone tasks, then select **Enable phone control**. Open [the mobile controller](https://d1gnr0x6ly7io1.cloudfront.net/control/) and sign in with the same account. Send prompts, choose green Guided/red Autonomous, and Pause/Resume/Stop. Keep the PC awake and unlocked; the connection expires after one hour. [Connection instructions and limits](remote-control.md).

**Resume after a banner:** the agent now replans from the current screenshot instead of repeatedly demanding verification of an earlier “click English” instruction. Autonomous remains Autonomous after resuming. Start a fresh task after updating/restarting the app.

Run the updated cloud pilot executable. An older extracted copy does not receive these changes automatically. The title bar identifies the cloud pilot; Preferences shows the build label.

1. Run `artifacts/windows-r15/DesktopGuide.App.exe`, or extract `artifacts/DesktopGuide-windows-x64-r15.zip`. Preferences identifies **Recovery + Voice Blob r15**. Sign in with your invited email and permanent Desktop Guide password. AWS, GCP and Railway credentials are separate. A successful sign-in becomes visible immediately; a service outage offers a retry without hiding the signed-in account.
2. Describe your task, for example **Open Chrome and guide me to book a train ticket on IRCTC**, then choose **Open browser & guide me**. Gemini interprets the goal and chooses a starting website, including ordinary typos; there is no website-name catalog or required URL. It can ask a concise clarification when needed. The app opens the chosen browser in a new window and starts live screenshot guidance. Name Edge or Firefox if preferred; Chrome is the default. Stop during planning prevents even a late result from opening the browser.
3. To get help with an already open application, press **Ctrl + Alt + Space** while it is in front. The floating companion names the window. Describe the goal and choose **Help with this window**. Merely pressing the shortcut shares no images. If the shortcut is occupied, use the companion and optional existing-window selection in the main panel.
4. The companion becomes a compact instruction card and requests focus for your task window. The instruction, cursor status and any error stay visible. A drawn cursor travels to the grounded target, then shows a ring, target outline and comment such as **Click here**. This visual guide does **not** require physical mouse permission. Reduced motion removes travel and pulsing. The card moves away from the indicated control when a free corner is available.
5. If the target is missing or the screen changed, the guide tries one fresh-image target search automatically. **Find click target** retries this same instruction; it does not mark it complete. **Check screen** checks the result of your action. Returning to the selected task window restores a still-valid visual marker. Expand the card for **Show me where**, questions, recording, Pause or a new task. Stale, masked, covered or uncertain targets are withheld and the card explains why.
6. Keep secrets and billing decisions under your control. Pause before entering sensitive information. Stop is always available on the dock, in the tray, and through **Ctrl + Alt + Shift + S** when registered. It cancels pending launch/sign-in work and ends capture. Resume requires fresh consent.

Choose **Guided** or **Autonomous** before starting. Autonomous mode needs the separate control checkbox and can click, scroll, type and verify in the selected/opened window for up to 30 dispatch attempts or 10 minutes. Move your mouse, press a key, Pause or Stop to take over. Resume needs fresh consent. Login, CAPTCHA, payments, deployment and final commitments remain manual. Native apps currently need to be opened and selected first; the prompt launcher opens browsers. See [autonomous scope and evidence](autonomous-mode-plan.md).

The floating animated 3D blob and interface are green in Guided mode and red in Autonomous mode. Click the blob once to open the prompt and listen, or choose **Type**. **Finish & transcribe** sends the recording (up to 30 seconds) to Gemini through AWS and places the words in the editable task box. Review them and press Start; transcription alone never starts control. Cancel, Stop or changing mode discards a pending recording/transcript. Voice input needs sign-in and an available microphone; typing remains available.

In Autonomous mode, an ordinary banner can be dismissed or scrolled within when the live image supports that action. A missing clickable target gets up to two fresh visual recovery decisions; no fixed IRCTC sequence or scroll coordinates are used. The agent still pauses for sensitive actions or unresolved uncertainty. **Resume** waits for the interrupted analysis to end, synchronizes the session, and analyses a new screenshot of the current page. It preserves your original task and does not assume that clicking Resume completed the previous step.

**Waiting for the page** means the live image shows a loading state. The app watches for visible changes and asks Gemini for the next instruction after the ready state is verified. It does not draw an invented cursor over a loading page. A lost response is retrieved using the same request ID without uploading another image or making another AI call. If recovery fails, the card asks you to pause/resume to synchronize.

Guidance now uses screenshots only, as requested. Windows accessibility/DOM/browser control inspection is disabled. Gemini chooses the next instruction from the current image; the dedicated 3.5 Flash-Lite computer-use locator can find the current target from a fresh image. Local geometry, privacy masks, focus checks and Stop still protect the displayed marker. No scripted click sequence or offline walkthrough is used. Guided mode shows the cursor and leaves clicks to you. Autonomous mode can execute ordinary actions after task-specific consent.

The main panel retains an optional window/preview flow and privacy masks (`left,top,right,bottom`, normalized 0–1, separated with semicolons). There is no offline walkthrough. A cloud failure pauses guidance instead of presenting fabricated live steps. Closing the main panel leaves the companion/tray running; use **Exit** in the tray to quit.
